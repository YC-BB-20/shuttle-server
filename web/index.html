System files

Finder rewrites .DS_Store whenever a folder is opened, so a copy of one can never stay verified. Left-out files are counted on the copy, not hidden. Applies to new copies and verifies.

Start at login

Starts Shuttle in the background, with its menu bar icon, each time you log in. It does not start a second copy now, and Stop Shuttle in the menu bar keeps it stopped until the next login. The menu bar icon has the same switch.

Hash for copies

The hash every read of a copy makes: the source as it is copied, the copy read back, and the source read again. With both, each read makes both and both must match. Applies to new copies; a copy keeps the hash it started with, and a Verify reads each file with the hash its copy made. Each file's info shows the hashes.

Folder layout

The media folder is an exact copy of the source and nothing is added inside it; the hash list sits one level above, as destination/A001/hashes-20261116-2145.txt (year, month, day, hour, minute) beside destination/A001/A001/. These are the choices New copy starts from; each copy can change them, and the name can be typed there.

Disk speed test

The test writes one file, .shuttle-speedtest.tmp, at the top of the disk, reads it back with the Mac's cache bypassed, and repeats until you press Stop (at most 10 minutes). The file is removed when the test ends. A camera card or a read-only disk is only read.
