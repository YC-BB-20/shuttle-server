System files

Finder rewrites .DS_Store whenever a folder is opened, so a copy of one can never stay verified. Left-out files are counted on the copy, not hidden. Applies to new copies and verifies.

Start at login

Starts Shuttle in the background, with its menu bar icon, each time you log in. It does not start a second copy now, and Stop Shuttle in the menu bar keeps it stopped until the next login. The menu bar icon has the same switch.

Hash for copies

The hash every read of a copy makes: the source as it is copied, the copy read back, and the source read again. With both, each read makes both and both must match. Applies to new copies; a copy keeps the hash it started with, and a Verify reads each file with the hash its copy made. Each file's info shows the hashes.

Listing a waiting copy's files again

A copy's files are listed once, while you choose the folder, so the copy is sized the moment it is added. If it then waits in the queue longer than this before it begins, Shuttle lists the folder again first, so files added in the meantime are not missed. Never means it copies exactly the list made when it was added; a file that changed since is reported. Applies to copies that have not begun.

History

Hide an entry from its details in the history. Hiding only tidies the list: the copy, its files and its records stay as they are. The Hidden button among the filters does the same as this switch. Remembered in this browser.

Version history

Any recent green build, or any version kept on this Mac, can be installed. It is checked the same way as an update, and the version it replaces is kept. Copies pause and continue after the restart; an older version carries on with them in its own way, and nothing already verified is lost.

Disk speed test

The test writes one file, .shuttle-speedtest.tmp, at the top of the disk, reads it back with the Mac's cache bypassed, and repeats until you press Stop (at most 10 minutes). The file is removed when the test ends. A camera card or a read-only disk is only read.
